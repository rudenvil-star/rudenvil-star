### Hi, I'm Sávio Morais

I enjoy creativity, planning and the freedom to build something from the
first idea to the last detail. I'm also drawn to problems where information
is missing — where the question has to be framed before it can be answered,
and the way forward comes from investigating, testing hypotheses and deciding
with what's at hand.

That's the spirit behind the project I'm building now: a local-first desktop
writing platform for long-form authors, designed to give writers creative
freedom instead of a fixed method — built with Tauri 2, React 19,
TypeScript, Rust and SQLite.

The code is private; the **[case study](https://github.com/rudenvil-star/case-study)**
tells the story — the architecture, the decisions behind it and how the
manuscript's integrity is tested.

**Stack:** TypeScript · React · Rust · SQLite · Tauri · Vitest · Storybook

### Olá, sou Sávio Morais

Gosto de criatividade, de planejamento e da autonomia de construir algo da
primeira ideia ao último detalhe. Também me atraem os desafios em que falta
informação — quando a pergunta precisa ser formulada antes de ser respondida,
e o caminho sai de investigar, testar hipóteses e decidir com o que se tem.

de escrita local-first para autores de textos longos, pensada para dar
liberdade criativa em vez de impor um método — com Tauri 2, React 19,
TypeScript, Rust e SQLite.

O código é privado; o **[estudo de caso](https://github.com/rudenvil-star/case-study/blob/main/README.pt-BR.md)**
conta a história — a arquitetura, as decisões por trás dela e como a
